# Roadmap — Hermes Mobile

## Fase 1 — Estabilização frontend

- Preservar visual Lovable.
- Isolar mocks em serviços.
- Corrigir build/lint/TypeScript.
- Adicionar documentação e PWA básico.

## Fase 2 — Backend/API

- Evoluir a API local Bun/SQLite para autenticação, usuários e dispositivos pareados.
- Versionar migrations e seeds.
- Expandir persistência de sugestões, automações, permissões, chat e logs.
- Substituir endpoints simulados por integrações reais gradualmente.

## Fase 3 — Android

- Avaliar Capacitor vs TWA.
- Implementar permissões Android reais: notificações, acessibilidade, intents e armazenamento.
- Adicionar push notifications.

## Fase 4 — Hermes PC

- Pareamento seguro com desktop.
- Sincronização de tarefas e arquivos.
- Canal em tempo real com confirmação de ações sensíveis.
